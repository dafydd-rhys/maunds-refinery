Lists of Carnival Wisdom

Things Goblins Recommend

  • Use the same inline style several times so extraction has something obvious to find.
  • Repeat list item styling to test class generation and shared declarations.
  • Mix semantic elements so the serializer has more real-world structure to preserve.
  • Keep everything inline, because goblins fear stylesheets.
